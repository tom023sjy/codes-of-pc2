## 最大值或最小值(maxmin)

5s 1024mb

## 题目描述

你有两个长度为 $n$ 的排列 $a$ 和 $b$。

你最初持有一个元组 $(x,y)=(a_1,b_1)$。

接下来，对于索引 $i=2,3,...,n$，你必须依次对元组执行以下**二选一**的操作：

- **操作 Min**：更新 $x \gets \min(x,a_i)$，同时 $y \gets \min(y,b_i)$。
- **操作 Max**：更新 $x \gets \max(x,a_i)$，同时 $y \gets \max(y,b_i)$。

在执行完所有 $n-1$ 次操作后，他会得到一个最终的元组 $(x,y)$。

对于每个 $k$（从 $0$ 到 $n−1$），计算有多少种**不同的最终元组** $(x,y)$ 能满足 $|x-y|=k$。

## 输入格式

- 第一行是一个整数 $n$。
- 下一行包含 $n$ 个整数表示 $a_i$。
- 下一行包含 $n$ 个整数表示 $b_i$。

## 输出格式

输出一行 $n$ 个数表示答案

### 样例输入 #1

```
2
1 2
2 1
```

### 样例输出 #1

```
2 0
```

### 样例输入 #2

```
5
2 4 1 5 3
2 4 1 5 3
```

### 样例输出 #2

```
5 0 0 0 0
```

### 样例输入 #3

```
5
1 2 3 4 5
5 4 3 2 1
```

### 样例输出 #3

```
2 2 2 2 0
```

### 样例输入 #4

```
8
5 8 3 4 2 7 1 6
4 6 3 8 5 1 2 7
```

### 样例输出 #4

```
5 5 2 2 1 0 0 0
```



## 说明/提示

**【数据范围】**

对于 $100\%$ 的数据，$n \le 5 \times 10^5$。
