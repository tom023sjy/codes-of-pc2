# 20260926Div2T1 Set 

## Notice

注意：**要用文件 IO！！！**，输入：`set.in`，输出：`set.out`

## Problem Statement

给定正整数 $𝑛$，计算 $𝑛$ 个元素的集合 $\{1,2,⋯,𝑛\}$，所有非空子集和的乘积取模 $998 244 353$ 后的结果。

## Input

一个正整数 $n$，表示集合大小。

## Output

一行，一个整数代表答案。

## Hints

以下是对于 *Sample 1* 的说明：

例如 $3$ 个元素的集合有 $7$ 个非空子集，分别为 $\{1\},\{2\},\{3\},\{1,2\},\{1,3\},\{2,3\},\{1,2,3\}$，对子集内元素求和再乘积的结果就是$1\times 2\times 3\times (1+2)\times (1+3)\times (2+3)\times (1+2+3)=2160$

以下是测试范围的说明：

| ---------- | ----------- |

| $4\sim 6$  | $n\leq 20$  |
| $7\sim 9$  | $n\leq 50$  |
| $10$       | $n\leq 200$ |
